# Fix: L3 convergence line chart missing 2000–2500ep tail

## Problem

The convergence figure (`output/figures/l3v3_conv_15t_ms.png`, generated by
`scripts/plot_l3_conv_protocol.py` from the CSV written by
`scripts/train_l3_convergence.py`) shows the smoothed line/band stopping at
episode 2000 while scatter points continue to 2500.

Root cause: `_rolling()` in both plot scripts uses
`np.convolve(y, kernel, mode="valid")`, which trims `w-1` trailing points.
With `w=5` and 20 eval points (125..2500 every 125), the output is 16 points
and `x = ep[:len(m)]` caps the line at episode 2000. Data is complete — the
plot just drops the tail.

## Fix

Replace `mode="valid"` convolution with edge-padded convolution so the smoothed
series keeps the full input length:

```python
def _rolling(y, w=5):
    y = np.asarray(y, dtype=float)
    if w <= 1 or len(y) < w:
        return y
    kernel = np.ones(w) / w
    pad_l = (w - 1) // 2
    pad_r = w - 1 - pad_l
    return np.convolve(np.pad(y, (pad_l, pad_r), mode="edge"), kernel, mode="valid")
```

Output length = n + (w-1) - w + 1 = n (full range preserved). Edge-padding
avoids the zero-dip artifacts of `mode="same"`.

## Files

- `scripts/plot_l3_conv_protocol.py` — `_rolling()` (line 36) [primary — this
  builds the figure the user views]
- `scripts/plot_l3v3_convergence.py` — `_rolling()` (line 44) [same bug in the
  paper-figure sibling script]
